## 🚨 TROUBLESHOOTING

### If Frontend Doesn't Load
1. Check both processes are running (backend + frontend)
2. Refresh browser (Ctrl + F5)
3. Clear browser cache
4. Restart frontend: Stop and run `npm run dev`

### If You See "No Data" in Analytics
1. **Make sure you're logged in first!**
2. Analytics requires authentication
3. Log in with admin/Admin@1234
4. Then navigate to Analytics

### If Login Doesn't Work
1. Verify exact credentials (case-sensitive)
2. Check backend is running (http://localhost:8080)
3. Check browser console for errors (F12)
4. Try clearing browser storage and logging in again
